# ADR 0008: A free alternative to Package Visualizer with a better user experience

- **Status:** Adopted
- **Date:** 2026-11-27
- **Ticket:** KYP-8

## Context

Package Visualizer, a free Salesforce Labs app, already covers much of the idea behind KYP (see `docs/product/idea.md`). Without a stated position towards it, there is no reason to build KYP and nothing to guide what the MVP should do differently.

## Decision

KYP is offered as an alternative to Package Visualizer: free as well, and with a better user experience.

## Consequences

- Positive: ease of use becomes the criterion for choosing and designing features.
- Negative: KYP overlaps with an existing app, so it has to be clearly easier to use to be chosen.
- Negative: that it can be is not validated (assumption A6), and Package Visualizer has not been tried.
- Negative: being free, it brings no direct revenue.

## Alternatives considered

The reasons for rejecting these are the assistant's assessment.

- **Replace Package Visualizer:** it would call for matching all its features, including those outside the MVP.
- **Complement it:** KYP would depend on partners using both and would leave the user experience of the overlapping views unchanged.
- **Charge for KYP:** a paid product would have to justify its price against a free one.
